# NY Times Most Popular Articles

This is a React Application that fetches and displays the most popular articles from The NY Times.

## Fetures
-Fetches the most popular Articles from NY Times API
-Displays a list of articles.
-When an article is clicked, it takes you to the detailed article.

## Technologies Used
-React
-Typescript
-Axios(For API Calls)
-Jest(For unit Testing)
-Tailwind CSS (for styling)

##SetUp

### Prerequisites
-[Node.js](https://nodejs.org/)
or
-[Yarn](https://yarnpkg.com/)


###Installation

```bash

2.Navigate to project directory:
cd ny-times-popular-articles

3.install dependencies
